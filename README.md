# Homebrew Tap for TermLoop

This is the official Homebrew tap for [TermLoop](https://github.com/feritzcan2/termloop), a native macOS terminal for AI coding agents.

## Installation

```bash
brew tap feritzcan2/termloop
brew install --cask termloop
```

## Updating

```bash
brew upgrade --cask termloop
```

## Uninstalling

```bash
brew uninstall --cask termloop
brew untap feritzcan2/termloop
```
